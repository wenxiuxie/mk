# 袋鼠闯关 Kangaroo Hop

A bilingual (English / 中文) math practice game for 3rd graders preparing for Math Kangaroo and AMC.

Play online: https://wenxiuxie.github.io/mk/kangaroo-hop/

- **训练营 Training Camp**: an animated mini-lesson, then 20 questions (10 multiple choice + 10 typed on a number pad), a 60-second mini game after every 10, and a Boss question at the end. Numbers change every round.
- **闯关岛 Islands**: the warm-up island (adapted from Math Kangaroo 2019 Level 1) and four topic islands.
- **小游戏乐园 Game corner**: 60-second games.

The course plan is in [训练营提纲.md](训练营提纲.md). Everything is plain HTML, CSS and JavaScript; open `index.html` in a browser, no install needed.
